# Changelog — AbyssalCore Drill

All notable changes are documented here following [Keep a Changelog](https://keepachangelog.com/).

---

## [1.1.0] — 2025-XX-XX
### Added
- New Cave Systems — procedurally-placed cave networks triggered by deep drilling
- Deep Industrial Tech Tree (18 new buildables, 9 craftable items)
- 4 additional minerals: Ironbloom, Deepfang Ore, Voidcrystal, Pressium
- Resource Pipeline — connects Deep Drill Platform to base storage
- Configuration file support (`AbyssalCoreDrill.cfg`)
- Partial multiplayer sync

### Changed
- Rebalanced mineral spawn rates at 2000m–3000m depth
- AbyssalCore Drill Arm heat generation increased 20%
- Deep Drill Platform now requires Abyssite (new endgame gate)

### Fixed
- Fixed crash when deploying platform on uneven terrain
- Fixed Prawn Suit animation glitch during drill arm switch
- Fixed minerals not appearing in Fabricator after discovery

---

## [1.0.0] — 2025-XX-XX
### Added
- AbyssalCore Drill Arm (Prawn Suit module)
- Deep Drill Platform (placeable structure)
- 8 new minerals: Abyssite, Thermalite, Nullite + 5 more
- New geological formations in deep biomes
- Full BepInEx + Nautilus integration
- Thunderstore manifest
